这些 PNG 和 GIF 均来自 PromptShelf-Open 0.1.0 在 macOS 上的真实原生窗口，通过安装包安装后操作录制。没有使用设计稿、浏览器仿制界面或 AI 生成的界面截图。

- `workflow-result.png`：最终 DMG 安装版通过本机 Ollama 的 OpenAI 兼容接口，使用 `gemma4:12b` 完成三步任务，材料为 `examples/demo-meeting.md` 中的虚构会议。
- `workflow-demo.gif`：同一安装版的第二次真实执行，展示准备、第一步、第二步、第三步和完成状态。由实际窗口截图合成，省略重复等待画面并调整停留时间；并非实时速度。
- `model-connection.png`：应用实际发现两个本机模型，并完成生成式连接测试；API Key 为空。
- `prompt-library.png`：在隔离提示词库中通过界面创建的三条示例提示词。
- `write-preview.png`：替换一个专门创建的测试文件前的实际确认对话框。取消时内容未改变，确认后保存结果与模型最后一步输出一致。
