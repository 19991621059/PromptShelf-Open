# 0.1.0 实测记录

日期：2026-10-14（北京时间）。平台：Apple Silicon，macOS 27.0.1（26A434），Apple Swift 6.4。应用版本 0.1.0，构建号 1，独立标识 `io.github.promptshelf.open`。

所有验收材料均为生成的虚构资料。提示词库、偏好和剪贴板使用隔离目录与隔离服务；没有迁移、读取或覆盖原版的真实提示词库。原项目开始时的 208 个已跟踪文件逐项 SHA-256 比对未改变。协作提示词日志留在原项目，未纳入公开仓库。

## 安装包

已实际挂载 DMG，将应用安装到独立的 `/Applications/PromptShelf-Open.app` 并启动；ZIP 也实际解压并验证。DMG 中的应用、ZIP 中的应用和安装后的应用逐文件比对一致，临时代码签名检查通过。发行包没有调试符号、私人配置、原仓库 Git 历史或第三方角色模板。

本机安装验证不等于 Apple 公证，也不证明带互联网隔离属性的安装包在其他 Mac 上没有 Gatekeeper 提示。当前没有 Developer ID 签名和公证。

公开发布后，已从 GitHub Releases 无登录下载 ZIP、DMG 和 SHA256SUMS，两个安装包的校验值均正确；下载的 ZIP 实际解压后签名检查通过，可执行文件与实测安装版一致。

## 性能检查的范围

记录了最初基线，也在同一台 Mac、相同测试资料和相同操作下，将基线候选与最终候选接续重测。模型无活动请求，未进行屏幕录制；系统其他后台负载没有锁定，因此以下是单轮内部计时，不是统计显著的优化结论。

| 相同操作 | 接续重测基线 | 最终候选 |
| --- | --- | --- |
| 200 次缓存可见性切换 | 141 ms | 115 ms |
| 102,089 UTF-16 单位，三尺寸布局和命中检查 | 557 ms | 556 ms |
| 30 次原生插入与可见区域布局 | 102 ms | 94 ms |
| 2,000 次窗口移动提交 | 208 ms | 191 ms |
| 2,000 条提示词同步保存，五次 | 9 / 8 / 9 / 9 / 9 ms | 9 / 9 / 9 / 8 / 9 ms |
| 80 次长文输入与缩放提交 | 51 ms | 49 ms |

内部回归另覆盖拖动阈值、快速反向、重复松开、八方向缩放、视图身份、选区、撤销和零强制全文布局。上述数字只反映内部 CPU / 磁盘 / 提交耗时。真实桌面已检查中文输入、选区、撤销、滚动、窗口放大恢复与保存；尚未完成持续鼠标反向拖动的帧率记录和输入延迟基准，不声称已通过所有流畅度验收。
